# US 01.2 - Integração de Dados Dinâmicos nas Pokémon Cards (VGC Overlay)

## 🎯 Objetivo (O que e por quê)
**O quê:** Substituir os dados estáticos (mock) das Pokémon Cards por dados dinâmicos: sprites da PokéAPI e top moves/items/abilities do Smogon Stats.
**Por quê:** O overlay precisa refletir dados reais de uso competitivo (VGC 2025 Reg G) para ser útil em transmissões reais. O formato visual existente é mantido; apenas os dados são enriquecidos.

## 🧠 Contexto de Expert
Overlays VGC profissionais exibem o build mais provável de cada Pokémon para auxiliar comentaristas e espectadores. Usar dados do Smogon Stats (endpoint público JSON, sem autenticação) elimina dependências de servidor e mantém o overlay funcional offline com fallback para os dados mockados.

## 📝 Fluxo de Experiência/UX
1. O overlay é carregado no OBS apontando para `/game-hud-l` ou `/game-hud-r`.
2. Imediatamente, os cards aparecem com os dados base (mock) — sem delay.
3. Em background, o hook `usePokemonTeam` busca em paralelo:
   - Sprite oficial da PokéAPI (cacheado em localStorage)
   - Stats do Smogon Stats JSON (cacheado em memória por 5 min)
4. Quando os dados chegam, os cards são atualizados silenciosamente com sprites reais e moves/items/abilities do Smogon.
5. Dados manuais (fornecidos no mock ou futuro painel admin) sempre têm prioridade sobre Smogon.

## 📝 Requisitos Técnicos

### Arquitetura
- **Feature Flag**: `VITE_POKEMON_DATA_ENABLED` (default: `true`). Para desligar: `.env` → `VITE_POKEMON_DATA_ENABLED=false`.
- **Desacoplamento**: lógica de fetch isolada em `src/lib/pokemon-data.ts`. Componentes UI nunca chamam APIs diretamente.
- **Sem breaking changes**: campo `hpCurrent/hpMax` removido da interface (não era exibido de forma útil no overlay VGC); campos `moves`, `abilities` adicionados.

### Arquivos criados/modificados
| Arquivo | Ação |
|---|---|
| `src/lib/pokemon-data.ts` | NOVO — helper de fetch PokéAPI + Smogon Stats com cache |
| `src/hooks/usePokemonTeam.ts` | NOVO — hook React que enriquece time base de forma assíncrona |
| `src/components/overlay/PokemonCard.tsx` | MODIFICADO — remove HP/health bar, adiciona item, ability, moves |
| `src/components/overlay/mockData.ts` | MODIFICADO — formato sem HP, com moves e abilities |
| `src/routes/game-hud-l.tsx` | MODIFICADO — usa `usePokemonTeam` |
| `src/routes/game-hud-r.tsx` | MODIFICADO — usa `usePokemonTeam` |

### Dados exibidos por card (somente):
- ✅ Nome
- ✅ Sprite (PokéAPI, oficial-artwork)
- ✅ Tipos
- ✅ Item (manual > Smogon top 1)
- ✅ Ability (manual > Smogon top 1)
- ✅ Moves (top 4 — manual > Smogon)
- ✅ Status (PAR/BRN/PSN/SLP/FRZ/FNT) — apenas cosmético
- ❌ HP/Health bar — removido (dado muda durante batalha, irrelevante para análise VGC)

### Cache
- Sprites: `localStorage` (chave `pkmn_sprite_v2_{slug}`) — permanente
- Smogon Stats: memória (`_smogonCache`) — TTL 5 min

### Fallback
- Se PokéAPI falhar → sprite null → card exibe "?" placeholder
- Se Smogon falhar → dados manuais do mock são mantidos
- Se `VITE_POKEMON_DATA_ENABLED=false` → apenas dados mock, sem nenhuma chamada externa
